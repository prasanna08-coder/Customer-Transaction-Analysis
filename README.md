# Customer & Transaction Analysis

## Project Overview

Analyzed customer transaction data to identify purchasing behaviour and influential demographic factors.

## Project Description

- Analyzed customer transaction data to identify purchasing behaviour and influential demographic factors.
- Performed exploratory data analysis and hypothesis testing to identify customer segments based on spending patterns.
- Generated actionable insights to support targeted marketing and customer retention strategies.

## Tools and Technologies

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Development Environment:** Jupyter Notebook

## Dataset Description

The project uses three datasets:

- `customers.csv` – Customer demographic information.
- `credit_profiles.csv` – Customer credit-related information.
- `transactions.csv` – Customer transaction information.

## Analysis Workflow

### 1. Data Import

- Imported customer, credit profile, and transaction datasets using Pandas.

### 2. Data Cleaning

- Identified and handled missing values.
- Removed duplicate records.
- Handled inconsistent values and outliers.

### 3. Exploratory Data Analysis (EDA)

- Analyzed customer demographics.
- Explored customer transaction and spending patterns.
- Examined relationships between customer attributes and purchasing behaviour.

### 4. Data Visualization

- Used Matplotlib and Seaborn to visualize customer and transaction patterns.

## Key Outcomes

- Identified customer spending patterns and demographic factors.
- Explored customer segments based on purchasing behaviour.
- Generated insights to support targeted marketing and customer retention strategies.

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Place the three CSV files inside the `data/` folder.
4. Open `Customer & Transaction Analysis.ipynb` in Jupyter Notebook.
5. Run the notebook cells in order.

## Conclusion

This project demonstrates the use of Python, data cleaning, exploratory data analysis, and visualization to understand customer transaction behaviour and generate business insights.
